About Subchunks

The Subchunks pass breaks down each chunk into smaller pieces based on speaker turns in the VTT subtitle file. This enables analyzing what each speaker said separately, allowing per-speaker sentiment and category analysis within the context of each chunk.

⚠️ Critical Requirement

⚡ Subchunks REQUIRES "Enable per-speaker subchunks" to be enabled in Chunk Analysis configuration!

Subchunks and per-speaker tracking are tightly coupled. When you enable subchunks here, the pipeline automatically enables per-speaker processing. If you disable per-speaker in Chunk Analysis, subchunks will be automatically disabled during analysis regardless of this setting.

Pass Control

Also requires:

  • Per-speaker tracks ENABLED in Chunk Analysis (⚙️ Configure Chunk Size)
  • VTT subtitle file with speaker information uploaded
When disabled: Analysis operates at chunk level only.

Execution Order

Default: 20. Lower numbers run first. Typical order: subchunks (20) → sentiment_pass (30) → categories_pass (40)

ℹ️ Requirements & Dependencies

To use Subchunks, you must have:

  • VTT Subtitle File - The transcript with speaker timing information
  • Per-Speaker Tracks Enabled - Must be enabled in Chunk Analysis configuration
  • Subchunks Pass Enabled - Toggle above to enable/disable

What Subchunks Does:

  1. Reads VTT cues to identify speaker turns within each chunk
  2. Breaks chunks into subchunks at speaker boundaries
  3. Each subchunk tagged with speaker information
  4. Downstream passes (sentiment, categories) can analyze per-speaker

When to Use:

  • ✅ Multi-speaker content (interviews, podcasts, debates)
  • ✅ Need speaker-level sentiment analysis
  • ✅ Need to attribute categories to specific speakers
  • ❌ Single-speaker or no VTT file available
