About Categories Pass

The Categories Pass assigns topic/category tags to transcript chunks during analysis. Configure the category system below to control how categories are suggested to the LLM and normalized.

Category Map (Aliases → Canonical)

Define how to normalize category aliases to canonical names. Example: "hiphop" → "Hip-Hop Music", "politics_us" → "US Politics"

Category Cache (Suggestions to LLM)

List canonical category names that the LLM should prefer when tagging chunks. Top 50 will be suggested to the LLM. One per line.

Pass Parameters

Auto-filtered Categories (Placeholders)

These categories are automatically filtered out during post-processing (common placeholder values). You can modify or add to this list if needed.

ℹ️ System Constraints
  • Case handling: All categories are normalized to lowercase during extraction
  • Pipe-delimited: Categories like "music|rock" are split into separate tags
  • LLM suggestions: Top 50 categories from cache are shown to the LLM
  • Deduplication: Duplicate categories are removed at chunk and aggregation levels
  • Storage: Categories stored in database as separate items with item_type='category'
  • No special characters: Only alphanumeric, spaces, and hyphens recommended
