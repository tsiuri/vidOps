About Speaker Filtering

Speaker filtering allows you to analyze only specific speakers' content. Useful for podcasts where you want to focus on the host's perspective, or interviews where you want specific speakers' segments only. Non-matching speakers' content is excluded from analysis entirely before chunking.

ℹ️ How Speaker Filtering Works
  1. Diarization Match: Your video must have speaker/diarization data (from timestamps or VTT)
  2. Filtering: When chunks are created, they're matched against speaker timestamps
  3. Exclusion: Non-matching speaker segments are completely excluded from analysis
  4. Subchunks: If per-speaker subchunks are enabled, only matching speakers get subchunks
  5. Impact: Reduces analysis scope, potentially faster analysis on subset of content

Example: Podcast with Host and 3 Guests. Select "Include" mode and check only "Host" to analyze only the host's segments. Guest segments are completely excluded.
